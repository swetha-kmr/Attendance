DATABASE STRUCTURE
================================================================================

Collections Created:
1. users                      - Employee & admin profiles
2. attendance                 - Daily attendance records
3. leaveRequests             - Leave request tracking
4. loginActivity             - Audit logs

Sample Data Structure:

users:
{
  uid, name, email, role (admin/employee), phoneNumber,
  department, designation, createdAt, lastLogin, status
}

attendance:
{
  uid, date, checkInTime, checkOutTime, status (present/absent/leave),
  workHours
}

leaveRequests:
{
  uid, employeeName, startDate, endDate, leaveType (casual/sick/vacation/personal),
  reason, status (pending/approved/rejected), approvedBy, approvalDate,
  createdAt, days
}

loginActivity:
{
  uid, status (login/logout), timestamp, role
}

SETUP REQUIREMENTS
================================================================================

Before deploying, you need to:

1. Create Firebase Project
   - Go to console.firebase.google.com
   - Create new project named "attendance-manager"
   - Note down 6 credential values

2. Enable Services
   - Enable Firebase Authentication (Email/Password)
   - Create Cloud Firestore database
   - Set up security rules

3. Create Demo Users
   - Create 2 user accounts in Firebase Auth
   - Create corresponding documents in Firestore users collection

4. Environment Variables
   - Create .env.local file
   - Add 6 Firebase credential values
   - Restart dev server

5. Collections
   - Create 4 Firestore collections (users, attendance, leaveRequests, loginActivity)
   - Add security rules
   - Add demo user documents

See QUICK_START.md for 10-minute setup guide
